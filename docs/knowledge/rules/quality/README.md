# Quality rules

Common init ships `coding-style.md` (language-agnostic Critical). Stack-specific
quality rules arrive via the `langs/` rewrite on apply. This project applied `java`,
so [java-coding-style.md](java-coding-style.md) is present and replaces the pack's
generic Java style with the team's agreed rules.

Rules in this category:

- [coding-style.md](coding-style.md) — language-agnostic coding style (Critical)
- [java-coding-style.md](java-coding-style.md) — Java 编码风格（团队约定）
- [naming-conventions.md](naming-conventions.md) — 跨端命名速查与术语唯一性（团队约定）
- [web-coding-style.md](web-coding-style.md) — 前端 Web 编码风格（团队约定）

# evolve brainstorming agenda

Use Superpowers brainstorming: **one question at a time**. Record each answer in
the checkpoint log before writing the proposals report.

| id | topic | Typical choices |
|---|---|---|
| C1 | Evidence scope | `summary-only` \| `summary+verify` \| `thin-context` |
| C2 | Focus | `harness` \| `rules-adr` \| `both` \| `all` |
| C3 | AO / AI4SE extra asks | free-text notes / `none` |

**Execution root:** Not a brainstorming checkpoint. Prefer the session-confirmed
root (see [execution-root.md](../../../../vendor/ai4se-plugins/references/execution-root.md)).
Standalone → ask once (technical) or use the path the user already named.

**change-id / change-summary:** Handled by prerequisite A′ in `SKILL.md` before
this agenda. Do not duplicate as C-ids.

Selecting which proposals to adopt (and any Rules apply) is **not** a
checkpoint. After the report, ask which items to hand to `/sdd:rules-govern`.
Never rewrite Rules inside this skill.

Skip only when the user already answered in this session; mark
`skipped-preanswered` in the log.
